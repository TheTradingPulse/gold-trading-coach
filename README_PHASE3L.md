# Phase 3L — Overnight Diamond Discovery Lab

This is a bounded, resumable, local-only research job designed to run for up to
10 hours. It looks for a few high-quality trades rather than maximizing signal
count.

Core method:

1. Read the canonical five-year professional-zone reference.
2. Purge overlapping setups before research.
3. Replay each remaining standard setup on the corresponding real micro market.
4. Require standard/micro agreement across 1R through 20R.
5. Link setups to the previously catalogued massive-move sessions for descriptive
   fingerprint discovery.
6. Search rules using development data only (2021-2023).
7. Validate on 2024, report untouched 2025 holdout, and stress actual micro costs.
8. Use remaining runtime for month-block bootstrap stability analysis.

The lab checkpoints every symbol and resumes after interruption. It performs no
network/API calls, purchases no data, and never modifies the dashboard, canonical
database, live scoring, or any prior result.
