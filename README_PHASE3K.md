# Phase 3K — Five-Year Micro Data Quote

Read-only Databento cost estimate for one-minute continuous-contract OHLCV from
2021-01-01 through 2026-01-01 for MGC, SIL, MES, MNQ, MYM, M2K, MCL, and MNG.

This package cannot purchase or download market data. It writes a per-symbol and
combined quote to `research_data/v7/acquisition/phase3k_micro_5y_quote.json` and
creates a small result ZIP in Downloads for review.
