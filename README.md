## 📊 Overview

# Gold Trading Coach V1

AI-assisted trading decision support system for Gold Futures (MGC/GC). Built for a private client.

---

## Description

A multi-timeframe analysis system that detects supply and demand zones, calculates trend alignment, and identifies high-quality trade opportunities with minimum 3:1 reward-to-risk ratios. Not an automated trading bot. Does not execute trades.

---

## Features

- 8 timeframe multi-timeframe trend analysis (Monthly to 1-Minute)
- Automated supply and demand zone detection with strength scoring
- Trade opportunity scanning with entry, stop, and target calculation
- AI explanation engine for every trade setup
- Setup grading system (A+ to Avoid)
- News intelligence with economic calendar and confidence adjustment
- Chart screenshot engine across 5 timeframes
- Trade journal with full performance statistics
- Trade DNA engine for setup type analysis
- Historical backtesting engine (2000-2026, any single year or all years)
- Telegram bot with 9 interactive commands
- Web dashboard with live candlestick charts

---

## Tech Stack

Python, Streamlit, PostgreSQL, Polygon.io API, Yahoo Finance, python-telegram-bot, mplfinance, pandas, numpy, Railway (deployment)

---

## Performance

Backtested across 5 years of live data. Profit factor of 9.20. Positive expectancy. 50.8 percent total return with 11.4 percent maximum drawdown. Sniper strategy prioritizing quality setups over trade frequency.

Deployed and live. Private repository for client use.
