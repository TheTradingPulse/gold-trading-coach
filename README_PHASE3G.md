# Canonical Phase 3G — Account Feasibility

Adds a reusable account-risk engine and validates the existing V6 evidence under a configurable Apex 50K baseline. Version 2 uses the advertised $50,000 balance as requested: $500, $1,000, and $1,500 at 1%, 2%, and 3%. The $2,000 trailing drawdown and $1,000 DLL remain visible as separate compliance warnings. It automatically chooses standard or micro contracts, enforces contract equivalence, rejects excessive execution costs, and reports minimum bankroll requirements.

The research runner tests only 1R–5R and promotes nothing live.
